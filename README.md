# Undertale-Boss-1
# [🚀 แตะเพื่อเปิดแอป 🚀](https://aomsinjaroensuk15-stack.github.io/undertale-boss-1/)

📖 รายละเอียดและวิธีเล่น (Game Overview)

เกมนี้เป็นเกมแอ็กชันสไตล์บอสไฟต์แรงบันดาลใจจาก Undertale ที่ผู้เล่นจะได้รับบทเป็นผู้ปลดปล่อยพลังงานทำลายล้าง เพื่อกำจัด "หัวใจสีแดง (DETERMINATION)" ที่มีความสามารถในการหลบหลีกขั้นสูงสุด!

🎯 เป้าหมายของเกม (Objective)

เป้าหมายเดียวของคุณคือ กำจัด (KILL) หัวใจสีแดงให้ได้ แต่เรื่องมันไม่ง่ายขนาดนั้น เพราะหัวใจดวงนี้สามารถคำนวณและ "หลบการโจมตีได้เกือบทั้งหมด!"

⚡ สกิลและคลังแสง (Boss Attacks)

คุณมีพลังทำลายล้างหลากรูปแบบไว้เลือกใช้กดโจมตี:

☠️ Gaster Blaster: ปล่อยลำแสงเลเซอร์พลังงานสูงจากหัวกะโหลกบีมยักษ์

🦴 Bone Barrage: สั่งพายุถั่งโถมกระดูกขึ้นมาจากพื้นในวงกว้าง

💥 Hyper Beam: ลำแสงเลเซอร์ทำลายล้างขนาดใหญ่แบบปูพรหมพื้นที่

🧠 กลไกการเล่นและวิธีเอาชนะ (Gameplay Mechanics & Strategy)

ระบบ Auto-Evasion (การหลบอัตโนมัติ): ทุกครั้งที่คุณกดปล่อยพลัง หัวใจจะคำนวณทิศทางและพุ่งหลบออกไปทันที ทำให้การโจมตีปกติแทบจะไม่โดนตัวเลย!

ค่า Stamina ของหัวใจ: ทุกครั้งที่หัวใจใช้พลังพุ่งหลบ ค่า Stamina (หลอดสีฟ้า) ของมันจะลดลงเรื่อยๆ

⚡ เทคนิคการเอาชนะ (How to Win):

กดรัวสกิลโจมตีอย่างต่อเนื่อง (Spam Attacks) เพื่อบีบให้หัวใจต้องกระโดดหลบไม่หยุด

เมื่อ Stamina ของหัวใจหมดลง มันจะติดสถานะ Exhausted (เหนื่อยล้า) และเคลื่อนที่ช้าลงอย่างมาก

อาศัยจังหวะที่มันเหนื่อยล้า กดปล่อยพลังใส่เพื่อสร้างความเสียหายใส่ HP ของหัวใจจนกว่าจะสังหารได้สำเร็จ!
